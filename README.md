# Speech Emotion Recognition

A deep learning project for recognizing emotions from speech using **CNN–LSTM** and **Transformer** architectures.

## Overview
This project investigates speech emotion recognition using the CREMA-D dataset, focusing on model performance across unseen speakers and different noise conditions.

## Key Features
- CNN–LSTM and Transformer model comparison
- Speaker-independent evaluation
- Hyperparameter optimization
- Mel-frequency feature selection
- Noise robustness evaluation
- Interactive dashboard for audio emotion prediction

## Emotion Classes
Angry · Disgust · Fearful · Happy · Neutral · Sad

## Technologies
Python · PyTorch · Librosa · FastAPI · React

## Dataset
[CREMA-D (Crowd-sourced Emotional Multimodal Actors Dataset)](https://github.com/CheyneyComputerScience/CREMA-D)
